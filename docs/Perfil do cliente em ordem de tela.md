## Perfil do cliente em ordem de tela

1. Cabeçalho do cliente
   - Foto
   - Nome completo
   - Idade
   - Sexo biológico
   - Telefone principal
   - Status

2. Ações rápidas
   - Nova avaliação
   - Abrir anamnese geral
   - Editar cadastro
   - Exportar dados do cliente

3. Resumo cadastral
   - Dados básicos
   - Contato
   - Responsável legal, se houver
   - Contato de emergência

4. Anamnese geral
   - Status da anamnese
   - Última atualização
   - Profissional responsável pela última revisão
   - Resumo técnico automático
   - Alertas relevantes
   - Criar anamnese, se não existir
   - Abrir / revisar / editar anamnese

5. Avaliações
   - Nova avaliação
   - Avaliações em rascunho
   - Avaliações finalizadas
   - Histórico antropométrico

6. Relatórios
   - Relatórios gerados a partir de avaliações
   - Visualizar relatório HTML
   - Exportar PDF

7. Observações internas
   - Observações gerais do profissional
