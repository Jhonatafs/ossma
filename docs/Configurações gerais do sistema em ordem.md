1. Aparência
   - Tema

   - Tamanho da fonte

2. Navegação
   - Posição da barra de navegação

3. Idioma e região
   - Idioma da interface
   - Formato de data
   - Formato de hora
   - País/região padrão

4. Backup local
   - Exportar backup local
   - Importar backup local
   - Incluir imagens no backup

6. Imagens

   - Remover metadados

7. Privacidade local e responsabilidade

   - Mostrar textos de ajuda nos campos
   - Mostrar avisos técnicos

9. Instalação e PWA
   - Status da instalação
   - Status offline
   - Atualização disponível

- Nome da aplicação
- Versão
- Licença
- Repositório
